# Battleship

A glowing neon-themed version of the classic **Battleship** game.  
Built with **HTML, CSS, and JavaScript** and supports both **Player vs Player (PvP)** and **Player vs Computer (PvC)** modes with interactive ship placement.

---

## ✨ Features

- Player vs Player mode (local multiplayer)
- Player vs Computer mode with medium level AI
- Interactive ship placement (manual or random)
- Hit and miss animations

---

## How to Play

1. Place all ships on your board to start the game.  
   - Ships can be placed horizontally or vertically.  
   - Every ship must be placed before the battle begins.  
2. Take turns choosing grid coordinates to attack. 
3. Sink all enemy ships to win.
